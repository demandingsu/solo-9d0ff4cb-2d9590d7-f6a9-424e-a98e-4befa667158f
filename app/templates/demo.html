一键演示数据

将创建 DEMO01（三天完整数据）与 DEMO02（中间一天缺测 11 小时）， 日期为最近三个已结束的 UTC 日，可分别验证成功发布与失败保留。

  1. 打开 概览，进入 DEMO01 站点页，选择完整日期，发布日报 → 得到 v1。
  2. 再次发布同一天（可修改备注）→ 得到 v2，v1 标记为历史，阈值快照各自冻结。
  3. 进入 DEMO02 站点页，选择缺测日期，发布 → 被拒绝，并显示每项缺测原因。
  4. 为 DEMO02 补传缺失小时后重新发布 → 成功，原失败记录仍可见。

curl：登记站点 + 上传观测 + 发布

# 1) 创建站点
curl -s -X POST http://localhost:8000/api/stations \
  -H 'Content-Type: application/json' \
  -d '{"code":"BJ001","name":"城东站","latitude":39.9042,"longitude":116.4074}'

# 2) 上传小时数据（宽表，UTC 整点）
curl -s -X POST http://localhost:8000/api/stations/1/observations \
  -F 'file=@samples/observations_complete.csv'

# 3) 发布指定 UTC 日
curl -s -X POST http://localhost:8000/api/reports \
  -H 'Content-Type: application/json' \
  -d '{"station_id":1,"report_date":"2026-11-20"}'

# 4) 查询当前版本
curl -s 'http://localhost:8000/api/reports?station=BJ001&report_date=2026-11-20'
